# Evidence-support reranking experiment

The six-question results below describe the original rubric. A later user-reported false rejection prompted a revised rubric and source-sentence selection. `--evaluate-reranking` now includes two additional cases: Moana's desired provider characteristics (supported) and the provider's name (absent). These are development regression cases, not a held-out benchmark.

Run: `dotnet run --project StudyRag -- --evaluate-reranking`.

This compares the original top-three candidates at similarity >= 0.60 with a second selection step using local `qwen2.5:latest` (7.6B, Q4_K_M) and `nomic-embed-text:latest`. The support rubric and selection threshold (retain 2 or 3) were fixed before running the six existing questions. Labels were inherited from the saved baselines, not generated by the reranker.

Full per-passage decisions, quotes and explanations: [support-results.txt](support-results.txt).

Class-material results on 2026-09-18:

| Method | Minimal-evidence precision | Evidence recall | Exact question sets |
| --- | --- | --- | --- |
| Similarity baseline | 60% | 100% | 1/3 |
| Support reranking | 100% | 100% | 3/3 |

Synthetic overlap: precision improved from 42.9% to 100%, recall stayed at 100%, and exact sets improved from 0/3 to 3/3. The reranker retained both scoped and singleton passages for the comparison and rejected the scoped passage for the unsupported memory-size question.

All twelve candidate assessments in this run parsed successfully and all six selected passages had matching source quotes. The recorded run preceded the addition of the separate invalid-assessment counter; that reporting/validation change was checked by unit tests without repeating model calls. No rubric or selection-threshold tuning followed the results.

The reranker kept Moana's passage, retained both Zara and Tane passages for the comparison, and excluded the generic communication passage. The medication-dose question had no candidates before reranking, so that case does not test the model's ability to reject unsupported topical evidence.

Selection success does not establish score accuracy. For Moana the model incorrectly said the provider preference was absent, although the passage explicitly mentions Pasifika health models. It assigned partial support (2) but still retained the correct passage. It also gave the fully answerable synthetic transient-lifetime passage a 2. Treat these values as an experimental selection rubric, not reliable probabilities or a verified distinction between complete and partial answers.

Exact source quotes are checked mechanically, but a real quote can still be irrelevant or insufficient. Invalid assessments are reported separately and cannot count as correctly empty or exact cases. Network/model failures abort the run instead of becoming unsupported-answer results.

The experiment measures passage selection only. The generation prompt now asks the model to acknowledge missing facts, but generated-answer abstention has not been evaluated here. Normal interaction retains similarity-only retrieval unless `--rerank` is supplied. Broaden the labelled corpus, test paraphrases, missing facts and multi-passage answers, and examine alternative sufficient evidence before enabling the feature by default.
